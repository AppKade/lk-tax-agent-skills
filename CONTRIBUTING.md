# Contributing

Read AGENTS.md and SECURITY.md before changing calculator code or skill workflows. Keep instructions concise, resolve bundled resources relative to the skill folder and preserve standalone execution without a server or sibling dependency. Do not use real taxpayer data in fixtures, issues or pull requests.

Rebuild the single helper and generated consent/intake references together after a source/dependency change and run the documented checks. Intentional changes to source files recorded in docs/migration.json must be labelled honestly rather than silently presented as unchanged migration code. Tax-rule changes require primary IRD evidence, exact locators, immutable history and qualified review under docs/rules-governance.md.

Scope a contribution to supported preparation, preserve current consent and unknown values, and explain remaining host/practitioner limits. Do not turn an illustrative source fixture, old requirement or comparison interpretation into a legal claim.
